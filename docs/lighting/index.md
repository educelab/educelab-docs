# Lighting

The lab has several types of lighting. Each type gets its own folder here.

| Type | Used for | Pages |
|---|---|---|
| MISHA LEDs | TBD | [Overview and color code](misha-leds/index.md) · [Inventory](misha-leds/inventory.md) |

## Adding a lighting type

Make a folder for it in `lighting/`, with an `index.md` overview.
If there's more than one unit, add an `inventory.md` table. Use
[MISHA LEDs](misha-leds/index.md) as the model. Then add a row to the table
above.
